# 평가 기준 (EVAL-CRITERIA.md)

> Evaluator가 코드 리뷰 시 사용하는 기준입니다.

---

## 평가 항목

### 1. 정확성 (Correctness)
- 요구사항이 완전히 구현되었는가?
- 엣지 케이스가 처리되었는가?
- 버그나 로직 오류가 없는가?

### 2. 코드 품질 (Code Quality)
- 가독성이 좋은가?
- 불필요한 복잡성이 없는가?
- 명명 규칙이 일관성 있는가?

### 3. 테스트 (Testing)
- 핵심 로직에 테스트가 있는가?
- 테스트가 실질적인 검증을 하는가?

### 4. 보안 (Security)
- OWASP Top 10 취약점이 없는가?
- 입력 검증이 적절한가?

---

## 평가 결과 형식

```
PASS     — 모든 기준 충족, 다음 TASK로 진행 가능
PARTIAL  — 일부 수정 필요, 구체적 피드백 포함
FAIL     — 재구현 필요, 주요 문제점 명시
```
